# החתמות מולטימדיה

מערכת לניהול החתמות והשאלות ציוד עבור סטודיו המולטימדיה.

## מה המערכת עושה
- כניסה לפי מספר אישי — כל אחד מזין מספר אישי בן 7 ספרות.
- חיילים רואים את היסטוריית ההשאלות שלהם ומבצעים החתמת ציוד עם חתימה דיגיטלית והפקת טופס.
- צוות הסטודיו מנהל את המלאי, ההשאלות, ההחזרות, יומן הפעולות והמשתמשים.

## הפעלה
פותחים את index.html בדפדפן, או נכנסים לכתובת ה-GitHub Pages של הריפו.
