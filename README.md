# החתמות מולטימדיה

מערכת לניהול החתמות והשאלות ציוד עבור סטודיו המולטימדיה.

## מה המערכת עושה
- **כניסה לפי מספר אישי** — כל אחד מזין מספר אישי בן 7 ספרות.
- **חיילים** רואים את היסטוריית ההשאלות שלהם ומבצעים החתמת ציוד עם חתימה דיגיטלית והפקת טופס.
- **צוות הסטודיו** מנהל את המלאי, ההשאלות, ההחזרות, יומן הפעולות והמשתמשים.

## טכנולוגיה
- קובץ HTML יחיד (React + Tailwind) שרץ ישירות בדפדפן — ללא התקנות.
- מתארח בחינם דרך GitHub Pages.
- מסד נתונים אופציונלי דרך [Supabase](https://supabase.com).

## הפעלה
פותחים את `index.html` בדפדפן, או נכנסים לכתובת ה‑GitHub Pages של הריפו.

## מצב הפעולה
כברירת מחדל המערכת רצה עם נתוני הדגמה מקומיים שאינם נשמרים בין רענונים.
לחיבור מסד נתונים אמיתי, ממלאים את פרטי ה‑Supabase בראש הקובץ `index.html`.
